# MNC Operations MIS Excel Dashboard

## Overview
MNC-level Operations MIS project built in Microsoft Excel using 5,000+ operational ticket records. The project simulates real-world MIS reporting, data cleaning, KPI analysis, SLA monitoring, cost analysis and management dashboard reporting.

## Key KPIs
- Total Tickets: 5,000
- Closure Rate: 79.38%
- SLA Achievement: 85.40%
- Avg Resolution: 12.79 Hours
- Avg CSAT: 4.45
- Rework Rate: 43.42%
- Operational Cost: ₹23.04M

## Analysis
- Data Quality & Cleaning
- KPI & Target vs Actual Analysis
- Business Unit Performance
- SLA Achievement
- Resolution Time
- Rework Rate
- Operational Cost
- Monthly Ticket Trends
- Interactive Slicers

## Excel Skills
Excel Tables | Formulas | Data Cleaning | IF | COUNTIF | SUM | AVERAGE | PivotTables | PivotCharts | Slicers | Conditional Formatting | Dashboard Design

## Business Insights
SLA achievement is below the 90% target, closure rate is slightly below the 80% target, and average resolution time is above the 12-hour target. Rework and operational cost were analyzed to identify key areas requiring management attention.

## Project Workflow
Raw Data → Data Cleaning → KPI Analysis → PivotTables → PivotCharts → Interactive Dashboard → Management Insights
